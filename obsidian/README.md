# LoveBites for Obsidian ❦

A writing pad that rewards you for writing, and a reader that looks like a book.

## What's in it

**Writing mode**
- Gliding pink caret; petals drift up as you type
- A bloom every 100 words, a celebration at your daily goal (500 by default)
- Typewriter scrolling that glides instead of jumping
- Fraunces headings that grow heavier when you hover them, a shimmering note title, a slow aurora behind each page, paper grain

**Reading mode** — click the `✎ Writing` pill in the status bar or press `⌘⇧B` (`Esc` returns)
- The note becomes a cream book page on a dim desk: stacked page edges, gutter shadow
- Justified, hyphenated, indented text; drop cap and small-caps opening line; running head
- Reading progress line and a "% · min left" folio

**Writing statistics** — click the goal ring in the status bar
- Today's words, streak, all-time total, best day, goal days, minutes writing, words per minute
- 16-week heatmap and 14-day bars

**Bookshelf** — `Home` shows every note in `Reading/` as a cover card (a Bases card view)

## Install

1. Copy everything inside `vault/` into a vault (or open `vault/` itself as a new vault).
2. Install the [Fraunces](https://fonts.google.com/specimen/Fraunces) font.
3. In Obsidian: **Settings → Community plugins → Browse**, install **Style Settings**, **Typewriter Mode** and **Homepage**. LoveBites Bloom is already in `.obsidian/plugins/`.
4. Restart Obsidian and turn on community plugins if asked.

Switches live in **Settings → LoveBites Bloom** (caret, petals, milestones, daily goal, follow macOS Reduce Motion) and **Settings → Style Settings → LoveBites Writer** (accent, column width, font size, line height, motion, aurora, grain).

New book: **Templates → Book Note**, then set `cover:` to an image in `Reading/covers/`.
